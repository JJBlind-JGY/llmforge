# LLMForge Infra v0.1.0-alpha.1

Release date: **2026-09-23**

## Purpose of This Release

`v0.1.0-alpha.1` marks the end of the repository-construction phase.

The project now has a coherent public surface for:

```text
GPU execution
Transformer runtime
LLM serving
scheduler / KV runtime
distributed inference
observability
evidence-driven optimization
cross-engine validation
```

It also has:

```text
public documentation
learning path
hardware tiers
compatibility policy
CPU-only examples
package metadata
CI/package-build validation
community health files
release-readiness audit
```

## What “Alpha” Means

This release distinguishes engineering completeness from experiment
completeness.

At this tag:

```text
repository engineering surface   complete
M1/M2 measured evidence          validated
M3-M8 engineering paths          present
M3-M8 full live validation       still in progress
```

Therefore this release must not be described as a production-proven inference
platform or as evidence that all M3–M8 performance claims have been completed.

## Validated Results

The public README contains only measured M1/M2 results.

Later performance numbers will be added only after their corresponding
experiment/report is complete.
